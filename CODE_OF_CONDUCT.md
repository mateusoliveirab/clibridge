# Code of Conduct

Clibridge follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
We expect collaborators to be respectful, constructive, and mindful that this
project may involve security-sensitive local execution.

Unacceptable behavior includes harassment, discrimination, threats, deliberate
exposure of another person's data or credentials, and publishing a security
issue in a way that puts users at risk.

For a conduct concern, use GitHub's reporting mechanisms or contact the
maintainer through the contact information on their GitHub profile. Reports will
be handled as confidentially as practical. This Code of Conduct applies in
issues, pull requests, discussions, and project-related community spaces.
